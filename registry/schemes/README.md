# Argument schemes

Reasoning patterns with attached **critical questions**, per
[DR-0034](../../docs/decision-records/DR-0034-argument-scheme-library.md).

Answering a scheme's critical questions — or failing to — is recorded as
argument structure (DR-0032/0033). This is OSINT verification practice
(Berkeley Protocol, DR-0008) expressed as data, and it operationalises
record §53: attributing deception requires answering *specific* questions
with evidence, not gesturing at falsity.

## Seed state

**Exemplars only.** DR-0034 assigns the seed library's contents to
methodology work, drafted with the METH documents and tested against the
first real investigations (SPEC-0004 §11 Q4; WP 0.6 §7 Q1). The two schemes
here establish the file pattern and the level of specificity expected; the
library grows by registry process (additive change, DR-0080).

Schemes still to be drafted, per DR-0034's named set: expert opinion,
sign/indicator, document authenticity, image/video verification, and
coordination/attribution.
