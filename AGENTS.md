# AGENTS.md

This file exists for tools that look for `AGENTS.md` specifically. The
actual working instructions for any AI-assisted session in this repository
are [`CLAUDE.md`](CLAUDE.md) — read that file whole before doing anything.

This is a pointer, not a fork. Duplicating CLAUDE.md's instructions here
would create two copies to keep in sync and, inevitably, drift — the
"Documents: where things go" section of CLAUDE.md exists precisely to avoid
that kind of duplication elsewhere in the project, and the same reasoning
applies to this file. If your tool reads `AGENTS.md` but not `CLAUDE.md`,
open `CLAUDE.md` yourself as the next step; there is nothing else here.
