# DR-0016 — CRMinf is the starting candidate for the epistemic/argumentation layers

**Category:** epistemology | **Status:** Approved | **Decided:** 2026-08-11 by founder/principal editor
**Origin:** CDR-W2-7, WP 0.3 §7 | **Supersedes:** — | **Superseded by:** —

## Context

WP 0.1 layers F (epistemic/assertion/evidence) and G (argument/inference) have no
selected standard. Workstream 2 identified **CRMinf** (argumentation extension of
CIDOC CRM: argumentation activities, beliefs, proposition sets, belief adoption,
inference making) as an established model covering much of this ground, natively
compatible with the adopted world layer (DR-0010).

## Alternatives considered

1. CRMinf as designated starting candidate for Workstreams 4–5 evaluation
   (chosen).
2. Adopt CRMinf now (rejected: it has not yet been tested against
   intelligence-analysis, legal-evidence, and structured-analytic requirements —
   record §103).
3. No starting candidate (rejected: wastes an established, compatible model;
   §94).

## Decision

CRMinf is designated the **starting candidate** — a study commitment, not an
adoption — for the epistemic and argumentation layers. Workstreams 4–5 must
evaluate it against: the record's provisional epistemic vocabulary (§30),
documentary-vs-world assertions (§32), competing hypotheses (§35), source
independence (§36), estimative language and confidence (§42), quantitative
assertion semantics (§44), negative evidence (§41, §48, §76), and
argumentation-theory requirements (§34, §103).

## Consequences

- Workstreams 4–5 start from evaluation, not invention.
- If CRMinf fails materially, the failure analysis itself defines the
  requirements for the alternative — either way the work compounds.
- No epistemic vocabulary freezes before that evaluation completes.
