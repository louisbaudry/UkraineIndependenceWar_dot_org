# DR-0025 — Adopt epistemic vocabulary v1

**Category:** epistemology | **Status:** Approved | **Decided:** 2026-08-11 by founder/principal editor
**Origin:** CDR-W4-2, WP 0.5 §6/§10 | **Supersedes:** — | **Superseded by:** —

## Context

Record §30 requires a small formal epistemic vocabulary established early and
expanded only when real cases require it.

## Alternatives considered

1. Six categories per §30, defined in the semantic registry (chosen).
2. Larger taxonomy up front (rejected: §30's expansion rule).
3. Free-text epistemic labels (rejected: uncontrolled vocabulary).

## Decision

Epistemic vocabulary v1 comprises six categories — **observation, claim,
assessment, hypothesis, finding, project conclusion** — with definitions as
drafted in WP 0.5 §6, to be entered in the semantic registry (record §101) with
multilingual labels governed by §60 terminology governance. Changes and
additions occur **only by Decision Record**.

## Consequences

- Every assertion in the system carries exactly one v1 category.
- Negative findings (§76) are findings — first-class, with scope and method.
- Publication wording maps from these categories via the presentation layer
  (§61), never ad hoc.
