# DR-0028 — Source dependence is explicit; corroboration counts independent lines

**Category:** epistemology / methodology | **Status:** Approved | **Decided:** 2026-08-11 by founder/principal editor
**Origin:** CDR-W4-5, WP 0.5 §8/§10 | **Supersedes:** — | **Superseded by:** —

## Context

Record §36: five publications repeating one original report are not five
independent confirmations. Historiographical method treats witness
interdependence as a core problem; the archive must not launder dependence into
corroboration.

## Alternatives considered

1. Typed dependence relations; independence as researched conclusion (chosen).
2. Independence assumed unless noted (rejected: defaults exactly backwards).
3. Numeric independence scores (rejected: false precision, §42).

## Decision

Where consequential, source dependence is recorded as **typed relations**:
cites, reposts, syndicates, derives-from, shares-underlying-document,
shares-underlying-witness, common-evidentiary-origin. **Corroboration counting
uses independent lines only**, where independence is a researched conclusion —
the established absence of dependence — never a default assumption.

## Consequences

- Confidence derivation (DR-0026) weights corroboration by independence.
- Transmission lineage (§23: reposts, mirrors, forwards) doubles as dependence
  evidence.
- Coordination analysis (§56) later reuses these relations.
