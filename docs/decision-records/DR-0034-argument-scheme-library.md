# DR-0034 — Seed argument-scheme library with critical questions

**Category:** epistemology / methodology | **Status:** Approved | **Decided:** 2026-08-11 by founder/principal editor
**Origin:** CDR-W5-3, WP 0.6 §2.6/§6 | **Supersedes:** — | **Superseded by:** —

## Context

Walton-style argument schemes render presumptive reasoning patterns — witness
testimony, expert opinion, sign/indicator — as reusable structures with
attached critical questions (structured defeater prompts). This is OSINT
verification practice expressed as data, and it operationalizes §53's rule that
deception attribution needs specific evidence.

## Alternatives considered

1. Seed scheme library in the semantic registry, extended by registry process
   (chosen).
2. Free-form argumentation without schemes (rejected: loses the critical-
   question discipline that prevents confirmation bias, §35).
3. Full Walton catalogue adoption (rejected: most schemes are irrelevant;
   seed-and-grow matches §30's expansion philosophy).

## Decision

A **seed argument-scheme library** is adopted, tuned to the project's evidence
types: witness testimony, expert opinion, sign/indicator, document
authenticity, geolocation, image/video verification, and coordination/
attribution. Each scheme carries its **critical questions**; answering them
(or failing to) is recorded as argument structure (DR-0032/0033). Schemes live
in the **semantic registry** (record §101); additions and revisions follow the
registry process rather than requiring a DR each.

Initial scheme contents are drafted with the methodology documents and tested
against the first real investigations (WP 0.6 §7 Q1).

## Consequences

- Attribution ladders (§52) and deception claims (§53) acquire scheme-specific
  evidentiary checklists.
- Review tiers (§78) can require critical-question coverage before
  publication of consequential conclusions.
