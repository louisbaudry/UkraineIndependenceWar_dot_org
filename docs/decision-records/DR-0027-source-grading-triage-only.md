# DR-0027 — Source grading is triage-only

**Category:** epistemology / methodology | **Status:** Approved | **Decided:** 2026-08-11 by founder/principal editor
**Origin:** CDR-W4-4, WP 0.5 §8/§10 | **Supersedes:** — | **Superseded by:** —

## Context

Record §37 forbids universal source-reliability scores determining proposition
truth: a propaganda outlet can publish an authentic document; a reputable
institution can err. The Admiralty/NATO tradition grades source reliability and
item credibility separately — useful, if confined.

## Alternatives considered

1. Two-axis grading, confined to triage/scrutiny/review-priority (chosen).
2. No source grading at all (rejected: triage needs some prioritization signal,
   §37 allows exactly this).
3. Reliability scores feeding truth status (rejected: §37 prohibition).

## Decision

An Admiralty-style two-axis grade — source reliability × item credibility —
**may** be recorded per source/item for **triage, scrutiny depth, and review
prioritization only**. It is **architecturally barred** from propagating into
any proposition's truth status, likelihood, or confidence: assessments
(DR-0026) must cite evidence and reasoning, never a grade.

## Consequences

- High-volume collection (§8–9) gains a lawful prioritization signal.
- Every proposition's status remains claim-relative and evidence-backed.
- Grades are themselves assessments with assessor and basis — revisable,
  provenance-bearing.
