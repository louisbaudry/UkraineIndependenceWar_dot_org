## Objective

Determine which established concepts, models, vocabularies, and standards already solve
the problems identified in Phase I — before any ontology, schema, API contract, or
technical stack is frozen.

## Governing constraint

> Do not start by asking what database tables to create.

Start with: what concepts already exist, what distinctions have mature disciplines
already made, and which standards can faithfully express the requirements discovered
in Phase I. Only then proceed to **Phase III — Conceptual Architecture**.

## Working convention

- Phase II outputs are drafted here as candidate documents. Nothing in this directory
  is canonical until approved by the founder/principal editor (record §78–79, §98).
- Candidate Decision Records are proposals; per §98 they are consolidated and submitted
  as a set for human approval, not mechanically generated one per Phase I question.
